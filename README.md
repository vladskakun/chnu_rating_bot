# CHNU Rating Telegram Bot

Telegram-бот для аналізу рейтингів вступників ЧНУ.

## Режими

### 1. Обрані спеціальності

Для кожної обраної спеціальності вводиться окремий
конкурсний бал. Останні 5 балів зберігаються окремо
для кожної програми.

### 2. Усі спеціальності

Один бал перевіряється в усіх освітніх програмах
зі сторінок `ALL_SPECIALTIES_URLS`.

### 3. Знайти себе у всіх рейтингах

Користувач вводить прізвище та ім’я, наприклад:

```text
Савчук Роман
```

Бот напряму переглядає таблицю загального конкурсу
кожної освітньої програми та виводить лише:

- назву спеціальності;
- місце в рейтингу.

По батькові вводити необов’язково. Порядок слів,
регістр і тип апострофа не впливають на пошук.

## Важливо: квотні рейтинги ігноруються

Парсер використовує виключно таблиці:

```text
Рейтинговий список абітурієнтів
(зарахування за конкурсом)
```

Таблиці:

```text
зарахування за квотою 1
зарахування за квотою 2
```

не використовуються ні для прогнозу місця,
ні для пошуку за ПІБ.

## Виправлення структури сторінки ЧНУ

На сторінці ЧНУ заголовок рейтингу може бути окремим HTML-елементом
перед таблицею:

```text
Рейтинговий список абітурієнтів
(зарахування за конкурсом)

<table>...</table>
```

Парсер тепер пов’язує таблицю з найближчим заголовком перед нею.
Завдяки цьому:

- таблиці загального конкурсу знову зчитуються;
- кількість заяв і бали не дорівнюють нулю;
- квота 1 та квота 2 залишаються проігнорованими;
- пошук за ПІБ працює по тих самих таблицях загального конкурсу.


## Критичне виправлення таблиць

Парсер більше не намагається визначати тип таблиці через текст
HTML-заголовка. Для кожної спеціальності він збирає всі таблиці
до наступного `h4` і бере останню:

```text
квота 1 → квота 2 → зарахування за конкурсом
```

Це відповідає фактичному порядку сторінки ЧНУ.

Якщо таблицю знайдено, але жодного рядка прочитати не вдалося,
бот показує технічну помилку замість помилкового прогнозу
«1 місце з 0 заяв».


## Місце відносно державного замовлення

Пошук за прізвищем та ім’ям показує:

```text
Автоматизація та комп'ютерно-інтегровані технології
Місце в рейтингу: 22 місце з 31 бюджетного
```

Якщо кількість місць державного замовлення не вдалося
прочитати, бот окремо повідомить про це.


## Рейтинг лише за пріоритетами 1–2

Бот додатково обчислює позицію, враховуючи тільки заявки:

- без позначки `ПЛ`;
- у полі пріоритету яких є окреме значення `1` або `2`.

Приклади:

```text
1       враховується
2       враховується
1,6     враховується
2,7     враховується
10      не враховується
4,9     не враховується
```

Під час пошуку за ПІБ бот показує:

- звичайне місце;
- кількість бюджетних місць;
- пріоритет знайденої заяви;
- місце за її балом серед заяв із пріоритетами 1–2.

Під час аналізу за введеним балом також показується
прогнозоване місце серед заяв із пріоритетами 1–2.


### Уточнення для пошуку за ПІБ

Якщо знайдена заява має пріоритет 1 або 2, бот показує її
реальне місце у відфільтрованому рейтингу.

Якщо заява має інший пріоритет, бот показує
`Умовне місце за балом серед заяв із пріоритетами 1–2`.
Власна заява не додається двічі до загальної кількості.


## Окремі бали для режиму «Усі спеціальності»

Після вибору другого режиму бот:

1. завантажує всі ОП зі сторінок `ALL_SPECIALTIES_URLS`;
2. залишає лише програми з таблицею загального конкурсу;
3. послідовно запитує окремий конкурсний бал для кожної ОП;
4. зберігає останні 5 балів окремо для кожної програми;
5. аналізує кожну програму з відповідним балом;
6. показує програми, де користувач проходить або перебуває
   на межі державного замовлення.

Під час довгого введення можна використати:

```text
/cancel
```

Старий один спільний бал режиму «Усі спеціальності»
більше не використовується.


## Повний результат режиму «Усі спеціальності»

Після введення балів бот більше не приховує програми,
де користувач не проходить на бюджет.

Усі проаналізовані спеціальності поділяються на:

```text
✅ Проходиш на державне замовлення
⚠️ Перебуваєш на межі
❌ Поза межами державного замовлення
```

На початку бот показує контрольну кількість:

```text
Усього проаналізовано: 17
Проходиш: 11
На межі: 0
Поза бюджетом: 6
```

Сума категорій повинна відповідати кількості програм,
для яких користувач ввів бал.

Для програм поза бюджетом додатково показується,
на скільки місць найкраща прогнозована позиція
нижча за межу державного замовлення.
