# CHNU Rating Telegram Bot

Telegram-бот для аналізу рейтингів вступників ЧНУ.

## Можливості

- аналіз обраних спеціальностей;
- окремий конкурсний бал для кожної обраної спеціальності;
- останні 5 балів окремо для кожної спеціальності;
- аналіз усіх спеціальностей з одним загальним балом;
- окрема історія останніх 5 балів для режиму
  «Усі спеціальності»;
- прогнозоване місце;
- кількість бюджетних місць;
- найближчі вступники вище та нижче.

Щоденної автоматичної розсилки в цій версії немає.

## Railway Variables

```text
BOT_TOKEN=ваш_токен
SCORE_DB_PATH=/data/user_scores.db
```

## Railway Volume

Підключіть Volume до сервісу з Mount Path:

```text
/data
```

У базі SQLite зберігаються лише історії останніх балів.

## Оновлення через GitHub

Замініть файли проєкту файлами з цього архіву:

```bash
git add .
git status
git commit -m "Remove daily reports"
git push
```

Railway автоматично створить новий deployment.

## Важливо

Стара таблиця щоденних підписок може залишитися у вже створеній
SQLite-базі, але нова версія коду її не читає і не використовує.
Ніякі автоматичні повідомлення надсилатися не будуть.
